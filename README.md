CodeAlpha E-commerce Sales Analysis

Project Overview

This project analyzes e-commerce sales data and customer reviews using Python, Exploratory Data Analysis (EDA), data visualization, and sentiment analysis.

Tasks Completed

- Task 2: EDA – Analyzed sales, profit, categories, regions, and top-selling products.
- Task 3: Data Visualization – Created charts to identify sales trends and profit patterns.
- Task 4: Sentiment Analysis – Classified customer reviews as Positive, Negative, or Neutral using TextBlob.

Tools & Technologies

- Python
- Pandas
- Matplotlib & Seaborn
- TextBlob
- Google Colab / Jupyter Notebook

Key Insights

- Analyzed sales and profit performance.
- Identified top-performing products and regions.
- Examined customer sentiment and ratings.

Conclusion

This project demonstrates how Python can be used to analyze sales trends, visualize business data, and understand customer opinions.
